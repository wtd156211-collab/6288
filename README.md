# 段合并策略（从 0 实现）

起始环境里只有这份说明、`samples/**` 与 `.gitignore`，实现要从零写：段合并键值存储、命令行入口与单文件报告。
Python 3.13 + 标准库，报告用原生 HTML 与内联 SVG，不引第三方、无构建、不联网。

## 一、范围

要做：按步重放一份「写入 / 删除」序列，每步落盘成新段，按第二、三节的容量与挑段口径合并到收敛；给出每步之后的键值视图与
指标；核对 `samples/expected/**`；生成自包含报告。

不做：事务、崩溃恢复（无 WAL 与 fsync）、并发与后台合并、Bloom 过滤器与读缓存、压缩加密、范围扫描、跨运行增量、
网络与第三方依赖；不改 `samples/**`，除 `var/` 与页面外不写别的文件。

## 二、口径与公式

- 键 1–64 字节 UTF-8，只含可见 ASCII（`U+0021`–`U+007E`）；值 1–255 字节 UTF-8；两者都不含制表符与换行，也不 trim。
- 写入即覆盖写，后写胜出；删除写墓碑，墓碑遮住更旧的同名记录，自己不出现在视图里。
- 行编码：`PUT<TAB>键<TAB>值\n`、`DEL<TAB>键\n`；`输入字节` = 累计输入操作按此编码的字节数。
- 段文件头行 `seg<TAB>L<层号><TAB><六位段号><TAB>记录行数\n`，其后每行 `PUT` 或 `DEL`，按键升序、每键至多一条。
  `落盘字节` = 段文件实际字节数（含头行与换行）；`累计落盘字节` = 曾写出的全部段之和（含已被合并删掉的）；
  `存活字节` = 当前存活段之和。
- 指标在每步合并收敛后统计，都按 `format(v, ".3f")` 写三位小数：
  - 写放大 = 累计落盘字节 ÷ 输入字节（输入字节为 0 时记 `0.000`）；
  - 读放大 = 存活段数（点查最坏情况下要看的段数）；
  - 空间回收率 = (累计落盘字节 − 存活字节) ÷ 累计落盘字节（累计为 0 时记 `0.000`）。
- 新旧：层号小的更新、同层段号大的更新；点查从新到旧扫，第一条含该键的记录说了算。
- 读接口：命中 `PUT` 返回值，命中 `DEL` 或哪段都没有就是「不存在」；合并只能改布局，不能改任何键的读结果。
- 视图 = 存活段按「新覆盖旧」归并出的键值列表，墓碑不出现，按键升序。

## 三、状态机与数据结构

一次 `run` 逐步重放：① 读入该步操作（同键多条只有最后一条生效，但每条都计入输入字节）；② 该步非空就落盘成 `L0` 段；
③ 反复找**层号最小**的越限层做一次合并，直到没有越限层；④ 写该步视图与指标。

容量（任一越限即触发）：`L0` 行数 ≤ 1024、`L1` ≤ 8192、`L2` ≤ 65536、`L3` ≤ 524288、`L4` 不限；`L0`–`L4` 段数都 ≤ 8。
段号是六位十进制，从 `000001` 起按创建顺序递增。

一次合并（口径写死），在该层按段号从小到大取段：只是段数越限就取该层**全部**段；行数越限就从最旧的段开始取，
取到剩下的段数与行数都回到上限内（至少 1 段）。

输入 = 取出的段 + 下一层里键区间与之有交的段（最底层改成本层相交的其它段）；键区间是段内记录的
`[最小键, 最大键]`。输入里同键只留最新的一条，输出按键升序写成一个新段，落到 `min(层号+1, 4)` 层、段号取当前最大值加一，
输入段随即删除；结果为空不写段。

墓碑回收：输出里的墓碑，只有当「比它所在的输入段更旧、又没参与本次合并的段」都不含该键时才丢掉，否则原样保留。
拿不准就保留：合并绝不能把删掉的旧值放回来。

## 四、输入输出与文件格式

负载 `samples/workloads/<名>.tsv`（UTF-8、LF、末行有换行）：`STEP<TAB>步号` 开一步（步号从 1 连续递增），其后是
`PUT<TAB>键<TAB>值` 或 `DEL<TAB>键`；`#` 行与空行忽略；单步 ≤ 20000 条操作，单份 ≤ 8 MiB。

```text
python -m segmerge run   <负载.tsv> <输出目录>
python -m segmerge read  <输出目录> <键>
python -m segmerge check <样例根目录>
python -m segmerge page  <样例根目录> <页面.html>
```

`run` 在输出目录写 `seg-<六位段号>.seg`、`report.tsv` 与 `views.txt`；`report.tsv` 首行表头，之后每步一行：

```text
step ops user_bytes disk_bytes live_bytes wa ra reclaim view_lines L0_segs L0_rows L1_segs L1_rows L2_segs L2_rows L3_segs L3_rows L4_segs L4_rows merges
```

`L<n>_segs` 与 `L<n>_rows` 按存活段文件统计，`merges` 是累计合并次数。`views.txt` 每步一组：`# step <步号>` 一行，
其后每行 `键<TAB>值`。

期望：`samples/expected/<名>.views.txt` 与 `views.txt` 逐字节相同；`samples/expected/<名>.marks.tsv` 表头
`step wa_max ra_max reclaim_min`，之后每步一行、三个数都是三位小数：该步写放大 ≤ `wa_max`、读放大 ≤ `ra_max`（结构上限 40）、
回收率 ≥ `reclaim_min`。

`check` 逐份跑 `samples/workloads/**`（输出写 `var/<名>/`），核对视图、门槛与容量不变量；全对时 stdout 一行 `ok=15`，
否则每处一行 `mismatch=<名>`、退出码 1。`read` 命中打 `键<TAB>值`，不存在不输出；用法错或负载不合法退出码 2，
错误走 stderr 一行 `error: …`。

报告：`page` 写自包含 HTML——内联样式、图形只用内联 SVG、无外链、`file://` 双击即开。按负载分节，画每步各层的段数与
行数、三个指标走势（门槛画虚线）与核对结论；顶部汇总负载数、步数与通过数。数字只取自 `report.tsv` 与期望文件。

## 五、性能与验收口径

测试机 Windows + Python 3.13、单进程单线程、冷启动计入；`05-scale` 十万条操作端到端 ≤ 20 秒、常驻内存 ≤ 256 MiB，
其余每份 ≤ 2 秒。同一负载连跑两遍，段文件、`report.tsv`、`views.txt` 与页面逐字节相同；不依赖随机数、时钟、哈希顺序
与平台换行。

1. `python -m segmerge check samples` 输出 `ok=15`。
2. 每步视图与期望逐行相同；每步对「至此出现过的每个键」点查，结果与该步视图一致。
3. 每步结束后各层段数 ≤ 8、行数不超上限；`report.tsv` 的段数、行数按第三节重算后与磁盘上的存活段一致。
4. 每步三个指标都落在门槛内；删除批之后的合并不许把删掉的键放回来。
5. 墓碑只按第三节的条件丢弃；越限层必须合并，挑段口径不许换。
6. 只用标准库、无构建、无网络；`python -m unittest discover` 能跑通，测试只读 `samples/`。

## 六、样例说明

`samples/workloads/*` 与 `samples/expected/*` 一一对应，期望文件是原文，逐行核对。

| 负载 | 规模 | 场景与看点 |
| --- | --- | --- |
| `01-overwrite` | 12 步 / 240 条 | 覆盖写：20 个热键每步整体覆盖；第 9 步段数越限触发合并，写放大 1.06–1.18 |
| `02-reclaim` | 6 步 / 2400 条 | 删除后回收：写 1200 → 删 900 → 补写 300；末步回收率 0.65 上下，存活字节比删前更小 |
| `03-coldhot` | 10 步 / 860 条 | 冷热混合：500 个冷键一次写入后不动，240 个分批写入，10 个热键每步覆盖，末步删 30 个冷键 |
| `04-smallbatch` | 40 步 / 87 条 | 小批量写：每步 1–3 条，段数触发的整层合并反复发生，读放大不超过 9 |
| `05-scale` | 5 步 / 100000 条 | 3 万键空间上覆盖写与删除混排，压时限与内存，数据只下到 `L2` |

`samples/notes.md` 是现场记录，只作背景，不作为口径。

## 八、实现说明

- 包结构：`segmerge/workload.py`（负载解析与校验）、`segmerge/segment.py`（段编码、新旧次序）、
  `segmerge/engine.py`（逐步重放、越限合并、墓碑回收、指标与视图）、`segmerge/checker.py`
  （视图/门槛/容量核对）、`segmerge/page.py`（自包含报告页）、`segmerge/cli.py`（四条子命令）。
- 补充输出：`run` 除三个约定文件外另写 `layout.tsv`（每步每个存活段一行：
  `step level segno rows tombstones bytes`），专供报告页画段布局；约定输出的格式不变。
- 测试：`python -m unittest discover`，只读 `samples/`，输出都写临时目录。
